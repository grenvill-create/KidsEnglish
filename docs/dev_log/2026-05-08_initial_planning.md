# 开发日志 - 2026年5月8日：深度规划与功能增强

## 1. 讨论内容总结
今天我们深入讨论了 KidsEnglish 的具体功能细节，特别是针对**听说能力**的提升以及**数据安全性**的保障。

## 2. 关键变更与新增
*   **功能增强：家长管理模式 (Parent Mode)**
    *   新增家长手动录入句子的功能，支持将课外或绘本中的句子添加进复习池。
    *   实现原理：前端输入 -> 云端数据库 (LeanCloud) 存储 -> 全设备同步 -> 孩子端复习显示。
*   **云服务推荐**：最终选定 **LeanCloud** 作为国内环境下的首选云供应商。其优势在于开发门槛低、免费额度高且国内访问极速。
*   **核心原则确立**：确立了“听说优先”的设计原则，所有的模块都将围绕语音输入和口语练习展开。

## 3. 技术细节确认
*   **同步机制**：不依赖浏览器本地缓存，全部进度实时推送到 LeanCloud 云端，解决误删数据风险。
*   **发音方案**：统一使用 Web Speech API，支持语速调节（慢速模式）。
