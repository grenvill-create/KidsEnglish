# 微信公众号文章交付排版规范 (WeChat Article Delivery Rules)

用户已明确要求：**后续所有生成的公众号文章，统一采用【方案二】排版规范，完全符合公众号后台复制排版需求。**

## 核心规则与执行细节：

1. **去除所有“分割线”**：
   - 严禁出现任何形式的分割线，包括 `---`、`━━━━━━━━━━━━━━━━━━━`、`------` 或波浪线等。
   - 段落与模块之间**纯粹依靠适度空行**自然分隔，保持版面干净清爽。

2. **每个段落小标题字号更大，方便排版**：
   - 正文大标题、每个词组小标题（如 `1. Dessert（甜点）vs. Desert（沙漠）`）以及核心板块标题，**字号必须明显放大**（采用二级大标题 `##` 或大号字体样式渲染）。
   - 这样用户从聊天框复制粘贴到微信公众号后台时，微信能直接识别为各级标题样式，字号自动变大，极大方便排版与美化。

3. **剔除所有容易引起公众号排版错乱的干扰语法**：
   - 严禁在正文列表中嵌套繁杂的 `* **...**` 符号和代码反引号 `` ` ``，直接输出清晰的标点或 Emoji（如 💥 翻车现场、💡 一眼记牢法、📌 速查卡）。
   - 严禁出现图片语法 `![...](...)`（改用清晰的上传提示，如：`【此处插入配图一：文件名.jpg】（配文说明）`）。
   - 严禁出现 Markdown 引用符号 `>`。

4. **语言与对齐要求**：
   - 严格保持 100% 逐句中英双语对照。
   - 整体版面层次分明，一键复制后直接粘贴到公众号后台即可轻松排版发布。
   - **文末难点词汇模块**：文章最后需简洁明了地附上【📌 本期难点词汇小词典 / Key Words to Know】，挑出 4~6 个适合儿童/读者掌握的重点或难点英文词汇，给出简明中文释义与简单记忆提示/例句。

5. **配图画风默认规范 (Illustration Style Preferences)**：
   - **历史 / 古典名著类文章**（如《水浒传》《西游记》、历史奇案、古代人物传奇等）：**默认统一采用宋明古风“绢本设色画”**（真实古绢细密丝织肌理、温润茶褐/暖米色古绢底、石青/石绿/朱砂/泥金天然矿物重彩、博物馆藏品级精细工笔线条）。画面戏剧张力与打斗场面采用**写实凌厉的古典武侠大片风格**（气势磅礴、兵器交锋、神情锐利、光影强烈），不再刻意弱化为低幼绘本尺度。
   - **亲子教育 / 英语学习类文章**：采用色彩鲜艳明快、高饱和度厚涂绘本风，避免画面雷同，场景紧密贴合正文具体比喻。
   - **通用铁律**：所有配图严格保持“一图一文件”（封面 1800×766 + 两张或四张 16:9 正文配图），纯艺术画面，绝对零文字、零字母、零印章、零水印。
   - **人物特征一致性与视觉验收铁律（血泪教训·严格执行）**：
     1. **严禁纯文字盲画导致人物“变脸/换装”**：每期（及跨期同角色）必须先锁定 1 张最标准的**基准参考图**（面容、光头/发髻、头饰细节、胡须、服饰配色与纹样、绢本底色肌理均完美达标），再把该参考图的本地绝对路径直接传给生图工具作为**视觉参考（Image Reference）**，确保其余所有图的人物长相、头饰（如鲁智深必须是素银圆扣戒箍，严禁画成孙悟空紧箍咒或长出两侧头发）、服饰和温润茶褐古绢底色 **100% 统一**。
     2. **严禁出现画风漂移与伪绢本**：古画类每张图都必须是真实的**温润茶褐古绢细密丝织底色**（全画幅铺满，严禁出现白底漫画风、现代亮蓝天空或四周留白画框）。
     3. **交付前必须强制视觉自检**：所有图片保存到本地后，必须先用视觉工具逐张检查人物特征一致性与绢本画质感，确认无误后再交付给用户！
