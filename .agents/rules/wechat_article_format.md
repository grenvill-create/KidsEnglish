# 微信公众号文章交付排版规范 (WeChat Article Delivery Rules)

用户已明确要求：**后续所有生成的公众号文章，统一采用【方案二】纯净无格式文本交付，严禁输出带有原生 Markdown 标记的内容。**

## 核心规则与执行细节：

1. **禁止出现原生 Markdown 语法标记**：
   - 严禁出现 `#`、`##`、`###` 等标题符号（直接输出标题文字）。
   - 严禁出现加粗标记 `**文字**`（直接输出文字，或使用微信常用的标点/括号/Emoji 突出）。
   - 严禁出现代码反引号 `` `s` `` 或 `` `code` ``（直接输出字母或单引号 `'s'`）。
   - 严禁出现 Markdown 引用符号 `>`（改用【导读】、【速查卡】或 Emoji 提示块）。
   - 严禁出现 Markdown 横线 `---`（改用优雅的线条符号如 `━━━━━━━━━━━━━━━━━━━` 或空行分隔）。
   - 严禁出现图片语法 `![...](...)`（改用清晰的上传提示，如：`【此处插入配图一：文件名.jpg】（图片描述/配文字说明）`）。

2. **版面与可读性优化**：
   - 保持 100% 逐句中英双语对照。
   - 段落之间保留适度空行，方便用户在手机微信与公众号后台浏览。
   - 关键栏目使用醒目的 Emoji（如 💥 翻车现场、💡 一眼记牢法、📌 速查卡 等）。
   - 用户可直接在聊天界面一键“复制全文”，粘贴到公众号编辑器时 100% 不乱码、不需要手动清码。
