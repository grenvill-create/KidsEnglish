# 20期儿童双语版《水浒传》系列总规划

## 一、系列规范
1. **文字风格**：儿童易于理解、简单生动，去血腥残忍，保留勇气、智慧、助人、团结与侠义内核。
2. **双语与排版**：100% 逐句中英双语对照；无分割线、小标题字号加大、无杂乱 Markdown 符号（公众号纯净排版）。
3. **文末必备模块**：每期文章最后附上简洁易懂的【📌 本期难点词汇小词典】（4~6 个难点英文词 + 简明释义 + 简单记忆/例句）及 1 个亲子互动小问题。
4. **配图规范**：每期配 **5 张正宗宋代绢本设色古画**（1 张 2.35:1 公众号超清封面 1800×766 + 4 张 16:9 剧情连环画：起、承、转、合），纯画无字、无印章、无水印。
5. **人物特征一致性**：同一期及跨期登场的同一人物，必须严格锁定固定外貌特征（面型、胡须、发型/头饰、服饰主色调与纹样、标志性道具），确保 5 张图之间人物形象连贯统一。
