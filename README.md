# KidsEnglish App

KidsEnglish 是一个专为儿童设计的轻量级、高性能英语学习网页应用。支持手机、平板和电脑跨端无缝使用。

## 🎯 核心需求与设计原则
*   **交互体验**：反应快、流畅，适合儿童的童趣 UI（大按钮、鲜艳色彩、弹性动画）。
*   **多媒体支持**：纯正英文发音，低资源消耗。
*   **跨端支持**：完美适配手机、平板和桌面浏览器。

## 🛠 技术选型 (Technical Stack)
*   **核心框架**：**React + Vite**。极速启动和打包，提供丝滑的交互状态管理。
*   **样式方案**：**纯 CSS (Vanilla CSS)**。手写定制化样式，保证极致性能与响应式布局。
*   **语音引擎**：**Web Speech API**。调用浏览器原生的文字转语音功能（TTS），免去下载庞大音频包的麻烦。
*   **数据同步**：**轻量级云数据库 (LeanCloud / Supabase)**。
    *   实现学习进度的云端保存。
    *   **彻底防丢**：无论设备如何清理缓存都不会丢失学习记录。
    *   **多设备无缝同步**：白天在平板学习，晚上在手机复习，进度时刻保持一致。

## 📦 核心功能模块设计

### 模块 A：单词与短语学习 (Vocabulary & Phrases)
*   **互动闪卡 (Flashcards)**：正面显示卡通图片和英文，点击卡片翻转显示中文，并自动朗读发音。

### 模块 B：小故事与对话 (Stories & Dialogues)
*   **情景对话**：通过气泡对话框展示短小有趣的故事。点击句子即可高亮并伴随语音朗读，支持逐句跟读。

### 模块 C：基础问答互动 (Mini Games)
*   **听音辨图**：播放单词声音，从 4 张图片中选择正确的图像。
*   **基础拼写**：根据图片和读音，点击屏幕键盘填补缺失的字母（如 `A P _ L E`）。

### 模块 D：发音练习提示 (Pronunciation Hints)
*   **辅助阅读**：提供慢速朗读（Slow mode）按钮，并为重要单词提供音标或自然拼读提示。

### 模块 E：每日复习功能 (Daily Review)
*   **云端进度同步**：自动将每日学习轨迹同步至云端，确保数据安全并支持多设备进度无缝切换。
*   **智能复习箱**：优先展示近期新学或在游戏中答错的单词。
*   **游戏化复习**：“闪卡快速过关”等趣味形式，达成连续正确可触发奖励动画。

## 🚀 开发路线图 (Roadmap)
1.  **阶段一：项目初始化** (Vite + React 骨架搭建，全局基础 CSS)。
2.  **阶段二：核心模块** (单词卡片、Web Speech API 接入、AI 测试图片生成)。
3.  **阶段三：互动与游戏** (对话阅读器、小游戏互动逻辑)。
4.  **阶段四：联调与数据同步** (接入云数据库，实现跨端进度同步)。
