# KidsEnglish App

KidsEnglish 是一个专为儿童设计的轻量级、高性能英语学习网页应用。支持手机、平板和电脑跨端无缝使用。

## 🎯 核心需求与设计原则
*   **交互体验**：反应快、流畅，适合儿童的童趣 UI（大按钮、鲜艳色彩、弹性动画）。
*   **听说优先**：以听力输入和口语练习为核心，利用语音合成提供标准发音。
*   **多媒体支持**：低资源消耗，通过 Web Speech API 实时生成语音。
*   **跨端同步**：完美适配手机、平板和桌面浏览器，学习进度全平台实时同步。

## 🛠 技术选型 (Technical Stack)
*   **核心框架**：**React + Vite**。极速启动和打包，提供丝滑的交互状态管理。
*   **样式方案**：**纯 CSS (Vanilla CSS)**。手写定制化样式，保证极致性能与响应式布局。
*   **语音引擎**：**Web Speech API**。调用浏览器原生的文字转语音功能（TTS），标准且流畅。
*   **数据同步**：**LeanCloud (国内首选)**。
    *   实现学习进度的云端保存，支持多设备无缝同步。
    *   **彻底防丢**：无论设备如何清理缓存都不会丢失学习记录。

## 📦 核心功能模块设计

### 模块 A：单词与短语学习 (Vocabulary & Phrases)
*   **互动闪卡 (Flashcards)**：正面卡通图片，点击发音并翻转显示中文。支持“听说领先”模式。

### 模块 B：小故事与对话 (Stories & Dialogues)
*   **情景对话**：气泡对话框展示。点击句子高亮并朗读，支持逐句跟读练习。

### 模块 C：趣味互动小游戏 (Mini Games)
*   **听音辨图**：播放单词声音，选择正确图像。
*   **拼写挑战**：根据音标和读音，拼凑出完整的单词。

### 模块 D：家长管理中心 (Parent Mode - NEW!)
*   **手动录入**：家长可以手动添加孩子在其他地方学到的句子/短语。
*   **内容管理**：同步至云端后，这些内容会自动出现在孩子的复习任务中。
*   **发音预览**：录入时可即时试听发音效果。

### 模块 E：智能复习系统 (Smart Review)
*   **云端同步**：自动将每日学习轨迹同步至云端，实现手机、平板进度同步。
*   **复习宝箱**：系统自动筛选近期新学、家长添加以及掌握不牢的内容进行针对性复习。

## 🚀 开发路线图 (Roadmap)
1.  **阶段一：项目初始化** (Vite + React 骨架搭建，全局基础 CSS)。
2.  **阶段二：核心模块** (单词卡片、Web Speech API 接入、基础布局)。
3.  **阶段三：家长模式与数据接入** (接入 LeanCloud，实现句子录入与云端存储)。
4.  **阶段四：互动小游戏与复习逻辑** (完善游戏化反馈与复习算法)。
