# 用车申请自动化系统 (GUI 界面版)

基于 Python Tkinter + EasyOCR + Selenium 自动化的智能用车申请录入系统。

---

## 一、主要功能

1. **多模态 OCR 智能识别与提取** (`smart_extractor.py`)
   - **手机审批单 / 单列表单模式**：支持各字段键值对智能匹配。
   - **排车网页表格模式**：支持垂直列投影算法，准确提取多列排车表格中的出发地、目的地等信息。
   - **两列并排用车信息卡模式**：
     - 支持两列并排排版字段提取。
     - 支持目的地跨行（如“百色路88号博翠中心1号楼1” + “312”）自动续接合并。
     - 支持时间段（如 `09-02 12:30 ~ 09-02 13:20`）智能提取用车日期。
     - 支持从用车原因长文本中备用提取目的地。
   - **OCR 纠错字典**：自动校正易错地名与学校简称（如“青中心”、“本部”、“南模初中”等）。

2. **浏览器自动化回填与提交** (`界面版_20260326_复用浏览器.py`)
   - 复用现有已打开的 Chrome 浏览器（或自动启动）。
   - 自动登录、自动定位 iframe 表单、自动填入提取到的信息。
   - 提供直观的 GUI 界面，支持剪贴板图片粘贴识别、本地图片选择、字段编辑与一键提交。

## 二、业务固定规则

根据业务规范，系统施加了以下固定硬编码规则：
- **申请单位 (ApplyOrganize)**：`上海市南洋模范中学`
- **出发地点 (StartAdress)**：固定为 `零陵路453号`
- **起止时间 (CarTime / EndTime)**：固定为 `[识别日期] 07:30` 至 `[识别日期] 20:30`
- **同行人员2 (CCRY2)**：固定为 `郭老师`
- **车型 (VehicleType)**：固定为 `358`

## 三、快速开始

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 运行程序
直接双击或在命令行中运行：
```bash
python 界面版_20260326_复用浏览器.py
```

### 3. 操作流程
1. 打开程序后，点击【复用/启动浏览器】。
2. 截图后在程序窗口中按 `Ctrl+V` 或点击【选择图片】。
3. 系统将自动通过 EasyOCR 本地识别并填入界面表单（包括到达地点、用车人、电话、事由等）。
4. 确认信息无误后，点击【自动填入网页表单】或【一键提交】完成用车申请。

## 四、核心文件结构

- `界面版_20260326_复用浏览器.py`：主程序 GUI 与 Selenium 自动化流程。
- `smart_extractor.py`：多格式智能 OCR 解析引擎与纠错规则库。
- `config.json`：登录配置信息。
- `requirements.txt`：Python 依赖清单。
